PopDrop 0.10.0 cache-write and Shell-generation hotfix
Package revision: cache-write-shellgen-20260730
Preview helper protocol: 3

This package keeps the confirmed preview size and left/right placement fixes.

Additional cache fixes:

1. Once the panel has been hidden for CacheStartAfterHiddenSeconds, the
   low-priority serial cache pass starts even if the folder scan is long.

2. Cache generation tries WIC first. If WIC cannot decode a format such as
   WebP or AVIF, the hidden background pass may ask the registered Windows
   Shell thumbnail handler to generate a real thumbnail.

3. THUMBNAILONLY remains mandatory, so a generic file icon is never written
   into PopDrop's clear preview cache.

4. Shell thumbnails are now classified correctly as opaque or transparent.
   Opaque thumbnails use JPEG instead of being incorrectly forced to PNG and
   potentially deleted for exceeding CacheItemMaxKB.

Expected default output directory:
cache\preview-cache-v1\

Rebuild native\bin\x64\PopDropPreview.exe before running PopDrop.ahk.
