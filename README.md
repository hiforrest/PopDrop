# PopDrop

**不切换当前窗口，随时取用多个文件夹里的最近文件**

需要时出现，用完就走。适用于 Windows 10 / 11。

[下载最新版](https://github.com/hiforrest/PopDrop/releases/latest) · [使用指南](USAGE.md) · [更新日志](CHANGELOG.md)

当前版本：**v0.10.0**

</div>

## 为什么做 PopDrop？

假设你正在聊天、写文档或处理一个项目，临时需要发送刚刚修改过的文件。

文件并不难找。麻烦的是，你通常要先离开当前窗口，切到资源管理器或文件管理软件，找到文件，再切回来。只是拿一个文件，窗口和注意力却跟着来回切换。

> **窗口切换容易打断工作记忆。**

PopDrop 想解决的就是这段小小的打断：

1. 按下呼出快捷键，文件面板出现在当前窗口上方；
2. 找到文件，直接拖到微信、飞书、邮件或其他软件；
3. 拖拽结束后继续手头的事，面板自动隐藏。

默认快捷键是 `F2`，可以在设置中改成自己习惯、且不与其他软件冲突的组合键。

![PopDrop 临时置顶面板](https://h2cdn.appinn.me/original/3X/0/0/0000f0fe5198c9c17e8614c6375c2c4adc6a1158.avif)

PopDrop 的默认窗口是“临时置顶”模式：呼出时来到最前面，切换到其他窗口后自动隐藏。它不打算长期占据屏幕，也不打算取代你的文件管理器。

## 快速开始

1. 前往 [Releases](https://github.com/hiforrest/PopDrop/releases/latest) 下载最新发布包；
2. 解压到一个固定目录；
3. 双击运行 `PopDrop.exe`；
4. 按默认快捷键 `F2` 呼出面板。

打开托盘菜单中的“PopDrop 设置…”，就可以添加文件夹、建立工作区、更换快捷键，以及调整窗口和文件打开方式。

> 发布包中的 `PopDrop.exe`、`PopDropTransfer.exe`、`PopDropPreview.exe` 和
> `config.ini` 需要放在同一目录。
>
> 从旧版本升级时，建议先备份整个软件目录；v0.10 会自动迁移旧配置，并保留 `config.ini.bak`。

## 它能做什么？

### 集中的“显示”菜单

主面板顶部使用固定文字的“显示 ▾”按钮集中管理缩略图/列表视图、文件预览和近期栏。
缩略图与列表用圆点表示互斥模式，文件预览与近期栏用勾选表示独立开关；选择后立即
生效并写入现有配置，重新启动后继续保持。设置窗口中的对应开关也与菜单同步。

### 安静的文件内容预览

鼠标停在真实文件上，或用方向键、Home、End、Page Up、Page Down 移动焦点后，
PopDrop 会在主面板外侧显示不抢焦点的内容预览。预览与选择状态分离：单击、
Ctrl/Shift 多选不会让当前悬浮预览闪退；真正开始拖拽、框选、滚动、打开菜单或移动
窗口时会立即隐藏，操作结束后即使鼠标没有再移动也会自动重新命中。

图片会尽可能直接生成内容预览；Markdown、文本、日志、配置、常见代码及 CSV/TSV
会生成有界静态语义快照。PDF 预览默认关闭；在设置页确认下载可选 PDFium 后启用，
并以 Windows 内置渲染为后备
显示第一页；DOCX 优先通过隔离 Helper 和 Windows
IFilter 提取开头语义内容，必要时回退系统真实缩略图。首次生成超过约 120 ms 才显示
等待卡，5 秒后改为后台提示，12 秒达到硬期限。文件夹、缺失项目、普通文件图标和
仅在线云占位不会显示为内容预览。
PDFium 未安装时 PDF 仍会尝试 Windows 内置能力；DOCX 的具体格式取决于 Windows
IFilter。

设置中的“空格键快速预览”可选 Seer 或 QuickLook，默认关闭。Seer 使用官方
`WM_COPYDATA` 协议；QuickLook 只接受经过校验的桌面版/便携版绝对路径，Store 版
不会被假定具有命令行能力。PopDrop 不安装、不捆绑这些外部程序，也不模拟按键。

### 拖拽文件夹快速添加来源

将一次拖拽中全部可验证的真实文件夹放到顶部“＋ 添加为来源”，即可按原顺序追加为
当前工作区的 Files 来源；该操作只写配置，不移动、复制或修改真实文件夹。纯文件、
混合选择、网页和虚拟内容不会显示此区域，下方现有来源分组仍可正常命中。

### 在主面板管理来源

右键 Files 或 Launcher 来源的分组标题，可以打开来源文件夹、请求刷新、使用
“设置此来源…”精确定位到该来源的设置，或从当前工作区移除来源。移除只清理
PopDrop 配置及该 SourceId 的专属规则，不会删除、移动或修改真实文件夹；固定项和
其他工作区的同路径来源也会保留。

### 随时拿到几个文件夹里的新文件

可以把下载、桌面、文档、项目目录等文件夹添加到面板。每个文件夹独立分组，新文件和最近修改过的文件排在前面。

你不必先记住文件放在哪里，也不用为了拿一个文件切走当前窗口。

面板还可以显示 Windows 的近期打开记录；图片、视频和 PDF 会优先显示系统缩略图，也可以切换为文件名列表。

### 文件可以拖出去，也可以直接拖进来

![把文件拖进 PopDrop](https://i.see.you/2026/07/28/Nh6s/848dfb0.avif)

除了从 PopDrop 把文件拖到其他软件，也可以反过来，把本地文件、聊天软件中的文件或网页图片拖进指定分组。

拖拽时，目标分组会实时高亮。较大的内容可以在后台接收，“下载任务”窗口会显示进度，并支持取消、重试链接或打开目标文件夹。

从网页拖入图片时，如果来源同时提供缩略图和原图，PopDrop 会比较实际像素尺寸，尽量只留下更清晰的版本。

### 固定项：放在手边的临时文件架

把近期需要反复查看、修改或发送的文件放进“固定项”，下次呼出面板就能直接拿到；文件夹也可以固定。

固定项只保存路径记录。取消固定不会删除、移动或修改原文件。

### 多工作区：不同项目使用不同的一套面板

![切换工作区](https://i.see.you/2026/07/28/up1Y/dcd45d9.avif)

每个工作区可以保存自己的来源文件夹、显示规则和固定项。

例如，可以为日常工作、个人项目和临时任务分别建立工作区。切换项目时跟着切换工作区，不必把所有目录都挤在一个面板里。

工作区可以新建、复制、重命名和删除；删除工作区只会移除配置，不会删除真实文件。

### 右键菜单和工具动作

![PopDrop 右键菜单](https://i.see.you/2026/07/28/mQi0/2237f40.avif)

可以选择默认使用 PopDrop 的简洁菜单，或者完整的 Windows 系统菜单。按住 `Shift` 右击，可以临时打开另一种菜单。

同一个应用既可以作为文件的“打开方式”，也可以提供多个工具动作。例如，把一组文件逐个交给某个程序处理，或者一次性把全部文件传给压缩、转换等工具。

动作支持文件路径、所在文件夹、日期、大小等参数变量。具体配置方法和 7-Zip 示例见[使用指南：应用与工具操作](USAGE.md#应用与工具操作)。

### 快捷启动栏

把常用软件的快捷方式放进一个文件夹，再将该来源设置为 Launcher，就可以把它作为快捷启动栏使用，并通过文件名前缀自定义顺序。

详细设置见[使用指南：快捷启动文件夹](USAGE.md#快捷启动文件夹launcher模式v05)。

## v0.10.0 更新了什么？

这次更新的重点是文件内容预览：

- **鼠标与键盘预览**：支持主列表、固定项和最近栏，并遵循最后明确输入；
- **独立原生 Helper**：Shell、WIC、文件身份和缓存工作不进入主界面线程；
- **真实内容优先**：自有清晰缓存、PDFium/Windows PDF 首屏、Shell 已有缩略图、图片原文件缩放解码逐级回退；
- **安全缓存**：只为本次实际悬浮且尚无快照的项目在隐藏后低优先级生成；大小与修改
  时间未变时直接复用，单项不超过 2 MiB，并限制总量与项目数；
- **显示菜单**：一个紧凑入口管理视图、文件预览和近期栏；
- **配置与设置**：预览开关、侧边和后台清晰缓存保存后立即生效。
- **文档识别**：Markdown/文本/代码/CSV 静态语义页、PDF 第一页和 DOCX 开头内容；
- **可选空格集成**：用户主动启用后使用 Seer 或 QuickLook，失败时保留原空格行为。

完整的版本变化请查看 [CHANGELOG.md](CHANGELOG.md)。

## 文件会被复制、移动，还是只被记录？

拖放到不同区域时，含义并不完全相同：

| 拖放方式 | 默认行为 |
| --- | --- |
| 从资源管理器等外部位置拖到普通文件夹分组 | 复制到目标文件夹 |
| 从 PopDrop 的一个普通文件夹分组拖到另一个分组 | 移动到目标文件夹 |
| 拖到“固定项” | 只保存路径记录，不操作原文件 |
| 拖到 Launcher | 为普通项目创建快捷方式；已有 `.lnk` / `.url` 只复制 |

在普通文件夹分组之间拖放时，可以按住 `Ctrl` 请求复制，或按住 `Shift` 请求移动。执行前请留意面板显示的目标和动作提示。

PopDrop 不会静默覆盖同名文件。复制、移动和移入回收站使用 Windows 的文件操作机制；按 `Delete` 删除时，如果无法移入回收站，不会自动改成永久删除。

后台接收的内容会先写入隐藏的临时文件，完成后再正式落盘。公开 URL 下载不会读取浏览器 Cookie、密码或登录状态，也不会自动打开下载结果。

更多边界和安全说明见[使用指南](USAGE.md)。

## 它和文件管理器是什么关系？

资源管理器、Total Commander、Directory Opus、XYplorer、Double Commander、
FreeCommander XE、Files 适合浏览目录、批量整理和重度文件操作。

PopDrop 负责的是另一个场景：在你不想离开当前窗口时，把近期文件递到手边，或者临时接住一个文件。

二者不是替代关系，可以同时使用。

## 已知限制

- 仅支持 Windows 10 / 11；
- 不同管理员权限级别的软件之间，拖放可能被 Windows 阻止；
- “近期打开”依赖 Windows 的近期文件记录；
- HEIF、AVIF、WebP、RAW 等图片能否直接预览取决于系统是否安装对应 WIC 编解码器；
- PDF 第一页预览默认关闭；设置页可按架构下载可选 PDFium，未安装时不增加基础包
  体积；
- DOCX 语义内容依赖 Windows IFilter，复杂浮动排版、分页、页眉页脚及嵌入图片不保证；
- 悬浮卡片是不可交互的识别快照，不提供滚动、选择、缩放、翻页或 Office 级排版；
- 网页和应用提供的拖放格式并不统一，依赖登录状态、私有格式或特殊请求头的内容可能无法接收；
- 软件使用 AutoHotkey 编写，少数安全软件可能误报，请从本仓库的 Releases 下载并自行判断。

## 键盘操作

| 操作 | 快捷键 |
| --- | --- |
| 打开所选项目 | `Enter` |
| 移入回收站 | `Delete` |
| 在文件管理器中显示 | `Ctrl + Enter` |
| 复制文件对象 | `Ctrl + C` |
| 复制完整路径 | `Ctrl + Shift + C` |
| 外部快速预览（启用且能力检测成功时） | `Space` |
| 关闭外部快速预览 | `Space` 或 `Esc` |
| 临时打开另一种右键菜单 | `Shift + 右键` 或 `Shift + F10` |

呼出快捷键、窗口模式、单击或双击打开等选项都可以调整。完整说明见 [USAGE.md](USAGE.md)。

## 从源码运行与参与开发

PopDrop 主程序使用 AutoHotkey v2，外部内容投放组件使用 Windows C++。
文件内容预览组件同样使用 Windows C++，不依赖第三方图像库。

只运行基础功能：

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)；
2. 将 `config.example.ini` 复制为 `config.ini`；
3. 运行 `PopDrop.ahk`。

从源码运行外部内容投放和文件预览时，还需要构建 `PopDropTransfer.exe` 与
`PopDropPreview.exe`。构建环境、命令和输出布局见
[native/README.md](native/README.md)。

遇到问题或有改进建议，欢迎提交 [Issue](https://github.com/hiforrest/PopDrop/issues)。反馈时如果能附上 Windows 版本、PopDrop 版本和复现步骤，会更容易定位问题。
