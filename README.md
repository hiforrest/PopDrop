# PopDrop

**不切换当前窗口，随时取用文件与文本**

需要时出现，用完就走。适用于 Windows 10 / 11。

[下载最新版](https://github.com/hiforrest/PopDrop/releases/latest) · [使用指南](USAGE.md) · [更新日志](CHANGELOG.md)

</div>

---

## 需要的东西，就在手边

正在聊天、写文档或使用 AI，临时要找一个文件、一段提示词，通常得先离开当前窗口，再翻目录、切窗口、找内容。

PopDrop 把这段过程缩短成几步：

> 按一下，找到，直接拖走或发送。

按 `F2` 呼出文件工作区；快速双击 `F2`，直达默认文本块工作区。快捷键和默认工作区都可以自定义。

![PopDrop 2.0](https://i.see.you/2026/08/20/2woB/v2-new-01.avif)

## 文件：找到，拖走

把下载、桌面、文档和项目目录放进 PopDrop。每个文件夹独立分栏，新文件和最近修改的文件排在前面。

呼出面板后，直接把文件拖进微信、飞书、邮件或其他软件。拖完继续手头的事，面板自动隐藏。

![img001.avif](https://i.see.you/2026/07/23/atE4/img001.avif)

文件也可以反向拖进 PopDrop，保存到指定文件夹；常用文件和文件夹则可以放进「固定项」，反复取用。

![拖入文件](https://i.see.you/2026/07/28/Nh6s/848dfb0.avif)

## 文本块：搜索，发送

PopDrop 2.0 新增文本块工作区，把 `.md`、`.txt` 文件平铺成卡片。提示词、常用回复、命令片段和写作模板，都可以放在这里。

- 输入多个关键词，快速筛选标题或全文；
- `Enter` 发送到原来的输入位置；
- `Ctrl + Enter` 插到已有内容前面；
- 直接拖拽文本块，精确放到想要的位置；
- 拖入文字或粘贴剪贴板内容，随手保存为文本块。

![键盘发送文本块](https://i.see.you/2026/08/20/R0ms/keyboard-send-text.avif)

> 双击快捷键，搜索，按下 `Enter`。全程不必离开键盘。

## 多个工作区，各管一摊

日常工作、个人项目、临时任务，可以各用一套文件夹、固定项和显示规则。

2.0 使用顶部 Tab 切换工作区。面板呼出时直接显示内容，不必等磁盘扫描；来源分栏可以单独折叠，也可以一键全部展开或收起。

![折叠来源分栏](https://i.see.you/2026/08/20/c6uZ/v2-new-collapse.avif)

## 2.0 还有这些更新

- **另存为定位到此**：从“保存 / 另存为”窗口呼出 PopDrop，一点就到目标文件夹；
- **悬停快速预览**：配合 Seer 或 QuickLook，鼠标停在文件上按 `Space` 即可预览；
- **界面自由调整**：缩放、缩略图、文件名行数、文本卡片大小和分栏间距均可设置；
- **快捷启动栏**：把常用软件集中到一个分栏；
- **右键动作**：自定义打开方式和带参数的工具操作。

完整变化见 [v2.0.0 发布说明](RELEASE_NOTES_v2.0.0.md)。

## 快速开始

1. 从 [Releases](https://github.com/hiforrest/PopDrop/releases/latest) 下载最新版本；
2. 解压到固定目录，运行 `PopDrop.exe`；
3. 按 `F2` 呼出面板；
4. 在托盘菜单中打开设置，添加文件夹和工作区。

从旧版本升级前，建议备份整个软件目录。PopDrop 会自动迁移旧配置。

## 说明

- PopDrop 免费使用，仅支持 Windows 10 / 11；
- 它负责快速取用和接收内容，不替代资源管理器、Total Commander 或 Directory Opus；
- 不同管理员权限级别的软件之间，拖放可能被 Windows 阻止；
- 软件使用 AutoHotkey 开发，少数安全软件可能误报，请从本仓库的 Releases 下载；
- 源码运行、构建方式和详细配置见 [BUILD.md](BUILD.md) 与 [使用指南](USAGE.md)。

遇到问题或有建议，欢迎提交 [Issue](https://github.com/hiforrest/PopDrop/issues)。
